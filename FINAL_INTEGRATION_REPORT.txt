ARCHITECTURE
================================================================================

HTTP Request Flow:

  Client Request
      ↓
  Gateway (app.py) - Route Matching
      ↓
  _payment_route Handler
      ↓
  PaymentRoutes (payment_routes.py)
      ↓
  Payment Service (payment/)
      ↓
  Response to Client

Path Matching Logic:
  - Gateway splits URL path into parts
  - Matches against known patterns (e.g., parts[:3] == ["api", "v1", "payments"])
  - Extracts relevant path components
  - Delegates to PaymentRoutes with method, path_parts, body, and user
