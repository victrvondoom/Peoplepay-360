# Demo runbook

```bash
make test
make demo-signoz
make sync
```

Open `http://localhost:8000`.

## Story

“Inflation is usually one abstract national number. InflationForge makes it tangible: one item, one city, two real receipts.”

Select rent, milk, eggs and gasoline. Click cities directly on the map and point to the previous/current dollar values, direction, ranking and source receipts.

Open **Manage items**:

“This is not a one-shot dashboard. It is a price-monitoring factory. The live source exposed 53 additional rows. I can add apples now, validate the source label and unit, and the next collection tracks it across every city—without rebuilding the application.”

Finish in SigNoz with the map’s trace ID, then show the related Port snapshot and item catalog.

## Presenter honesty

Say “observed city price-table values,” not “official CPI.” Say “Bright Data discovery” only when the UI mode does. A missing city stays missing.
