How routing works

PeoplePay selects enabled providers by capability, jurisdiction, priority and fallback rank. Providers supply evidence and proposals. ECHO owns decisions; Gateway owns authorized actions.

Connected endpoints require operator configuration. Procurement reference mode uses captured outputs and a simulated merchant. No production payments are enabled.
